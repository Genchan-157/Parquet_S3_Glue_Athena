# ParquetCompaction.py

## 開発目的
応えようとした需要
- S3のParquetファイル（1分毎なら1日1440ファイル）を統合したい

## 手段
- Lambdaで全ファイルをPyArrow Tableとして保持してから結合関数を呼び出す。
- 結合したテーブルはローカルディスク経由で行き先のS3 Prefixに書き込む
- Glue TableにPartition登録する（Partition追加だけならCrawlerより安い）

# 制限事項

## プリフィックス構成
読み取り元Prefix/year=yyyy/month=mm/day=dd/*datafile.paquet というパスを想定しています。
時間毎に集約する必要がる場合は、読み取り元Prefix側で時間まで識別する手段を用意して、コードをそれに合わせて修正してください。

## メモリ
Athenaで効率が良いとされているのは1ファイル128MB〜256MB程度なので、
1日1ファイルで大きすぎる場合は、1時間1ファイルなど粒度を変更して実装してみてください。
- データ量が多すぎる場合は、Lambdaのメモリが溢れたりします。
- 実行時間がかかる場合は、Lambdaの実行時間制限を超過する場合があります。

# IAM権限について

## アップロードするIAMユーザーの権限
IAMPolicy.jsonの設定を通常のLambdaの権限に追加

# 環境変数について
bucketでバケット名、databaseでGlueのデータベース名を指定しています。

# イベントについて
- src: 読み出し元プリフィックス（年月日より上位の部分）
- dst: 書き込み先プリフィックス（年月日より上位の部分）
- year: 処理対象の年
- month: 処理対象の月
- day: 処理対象の日
